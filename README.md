# Mechanistic Mind Observer — Acanthostega Beta 4.0

**Mechanistic Mind** is an experimental artificial-life / mechanistic simulation
environment. Observed behavioral structure should be treated as experimental
evidence requiring controlled comparison and ablation, not as evidence of
human-like cognition or subjective experience.

Do **not** treat observed behavior as proof of consciousness, intention,
recognition, communication, language, attention, learning, intelligence, or
goal-directed seeking.

## Zero-setup Linux package

The recommended way to run this release is the GitHub Release archive (bundled runtime):

1. Download `MM-Acanthostega-Beta-4.0-Final-Candidate.tar.gz`.
2. Verify SHA-256:
   `279bcdd8bb37a57d718df6fe7f2cdd762f8d7c8222e6453437e0c1e82b9d8e58`
3. Extract the archive.
4. Open the extracted directory.
5. Double-click **`MM Observer`**.

Ordinary users do **not** need system Python, a `.venv`, pip, Node.js, npm, a
source checkout, or manual backend start/stop. A graphical desktop and an
installed Chromium-family browser are required.

Optional terminal fallback: `./MM\ Observer`

Close the dedicated MM Observer window, or choose **More → Exit MM Observer**,
to stop the owned backend.
