# Release Notes

## Mechanistic Mind 2.0 — Tiktaalik: Undercover — Public Beta 1

Experimental research software for embodied agents in a shared physical world.

### Highlights

- Two-agent physical simulation with bounded cognition and prospective mechanisms
- Structured world: terrain / ecology / resources
- Physical near-field vision with visible bodies and LIVE **R=1 / R=2 / R=3**
- Illumination-aware optical sensing; anonymous `exo_*` channels only
- Physical signal fields (`FIELD_A` / `FIELD_B`) without assuming communication
- **Undercover**: one manually controlled physical participant (not cognitive injection)
- Psychology Observer UI with Sensors, Signals, interventions, and world status
- Analyzer with scientific history / provenance
- Visual Forensics and Signal Forensics (exposure ≠ recognition; signal ≠ message)
- Analyze Current uses scientific evidence history when available; otherwise historical metrics are `NOT_AVAILABLE`

### Not claimed

This Beta does not establish consciousness, language, recognition, intention, or social learning.

### Platforms

- Linux: primary packaging validation  
- macOS / Windows: launchers included; expect platform-specific setup friction
