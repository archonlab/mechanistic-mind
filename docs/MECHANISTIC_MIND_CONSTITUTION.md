# Mechanistic Mind Constitution

## Canonical research idea

Mechanistic Mind does not model finished personalities.

It models the emergence of persistent psychological patterns from the
interaction of:

- the same basic psyche architecture,
- an objective body,
- an objective environment,
- and a particular history of experience.

At simulation start, the agent has no preset personality, trust, anxiety,
avoidance, preferences, or beliefs about the world.

Conceptually:

```text
Agent(t=0)
=
basic psyche mechanisms
+ body
+ basic physiological needs
+ minimal experience
```

Differences should emerge after the simulation begins.

## Five levels that must remain distinct

```text
WORLD TRUTH
objective environment
        ↓
BODY TRUTH
objective physiology
        ↓
ACCESSIBLE SIGNALS
what the organism can actually sense
        ↓
AGENT MODEL
what the psyche has learned or inferred
        ↓
BEHAVIOR
actions produced by the current system state
```

Observer / ARCHON may inspect the full causal structure.

The agent may not.

## No preset psychological labels

The simulation must not require variables such as:

```text
trust = 0.3
anxiety = 0.8
avoidance = true
personality = "..."
```

If useful descriptions such as trust, avoidance, exploratory behavior,
resource hoarding, or stable preference are later applied, they should be
measurements or interpretations of an emergent trajectory whenever possible.

## Body truth is not agent knowledge

The Body Engine may know:

- mass,
- height,
- age,
- physical reserves,
- hydration,
- fatigue,
- damage,
- physical action costs.

The psyche does not automatically know these variables or their equations.

It receives only accessible signals and consequences.

For example:

```text
objective mass ↑
→ objective movement cost ↑
→ experienced effort may ↑
→ psyche learns from experience
```

There is no required rule:

```text
high_mass → sedentary
```

## Exogenous events

The World Engine must support events that are not caused by the agent.

Examples:

- resource disappearance,
- resource relocation,
- new resource appearance,
- terrain change,
- organism damage,
- stochastic environmental events.

The event's causal receipt is Observer truth.

The agent receives only what becomes perceptible or interoceptively
experienced.

This enables experiments on causal misattribution and learned controllability.

## History is a scientific variable

Three comparison classes are fundamental:

```text
same architecture + different worlds
same architecture + same world + different stochastic histories
same history until T + different intervention after T
```

The research question is not only:

> What does the agent do?

It is:

> What history of body × psyche × environment interaction made this behavior
> stable?

And:

> What intervention can move the system out of that state?

## ARCHON boundary

Mechanistic Mind owns:

```text
world
body
agent
interactions
history
```

ARCHON may later own:

```text
observation
measurement
hypothesis formation
intervention design
experiment execution
trajectory comparison
mechanism search
prediction
```

The scientific object is not a predefined "psychology of the agent".

It is the developmental trajectory through which persistent psychological
patterns emerge.
