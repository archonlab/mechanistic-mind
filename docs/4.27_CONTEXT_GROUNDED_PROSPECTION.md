## Research question

Can prospective composition operate over previously learned contextual structures rather than only low-level immediate transitions?

## Implementation

- Module: `mechanistic_mind/research/context_grounded_prospection.py`
- Config (default OFF): `context_grounded_prospection`
- Ablations: `_ablate`, `_shuffle`
- Learns bounded context→context transitions when successive contexts activate
- Composes via deterministic BFS (`MAX_COMPOSE_DEPTH=4`)
- Injects into PSC continuation list via bridge (`source=context_grounded_prospection`)

Pieces A→B, B→C, C→D are learned separately; full A→B→C→D is **composed**, not trained as one trajectory. A/B/C/D are analyzer labels only.
