# Update 4.38 — Psyche Incubation

This experiment asks whether predictive organization acquired from externally
caused physical body transitions contributes to the first later endogenous
intervention. `Psyche Incubation` is a researcher-side label only.

## Architecture inspection

The preimplementation audit found no causal route from a passive acquired
relation to present action logits. The existing non-WAIT source is stochastic
sensorimotor variation. The 4.26 route evaluates action-conditioned predicted
states through inherited targets and weights in `ordinary_state_value`; it does
not consume a passive object/body relation. Update 4.38 does not add that
missing interface.

`ordinary_state_value` reads energy, hydration, fatigue, and discomfort body
signals. Its target levels, signs, and weights are inherited. It therefore
contains a prior ordering of body states. In 4.38 it is reported as a diagnostic
and explicitly contributes zero to the autonomous probe logits.

## Protocol

Clean organisms receive 12/36/72 externally initiated interactions with X1–X3.
Only numeric physical features and ensuing body vectors enter learning. X4 is a
related, never-interacted instance; Y is an unrelated accessible instance.
Controls include no development, decorrelated development with matched volume,
same current body, acquired-structure ablation, compression/generalization
ablation, ordinary-state-value neutralization, body-consequence neutralization,
raw-history purge, and the spontaneous motor baseline.

Externally caused contact is never counted as endogenous action. WAIT advances
body dynamics. A stochastic interaction may occur, but it is not attributed to
acquired organization unless its distribution changes and selective ablation
removes the change.

Run with:

```bash
PYTHONPATH=. python3 experiments/run_update438_psyche_incubation.py
```

## Result

Across seeds 17, 23, 41, 59, and 83, passive experience, consequence learning,
compression, provenance, novel-instance prediction, structured/decorrelated
separation, matched-state history differences, raw-history independence, and
boundedness were asserted. Baseline stochastic interventions occurred, but
their probability was identical across learned, clean, decorrelated,
acquired-structure-ablated, and valuation-neutralized probes.

The first unsupported main arrow is:

`predicted available consequence -X-> present endogenous action influence`

Thus Mechanistic Mind acquired, compressed, and generalized predictive
structure concerning externally supplied body consequences, but this acquired
structure did not independently provide a causal basis for endogenous
intervention in the tested architecture. This is Outcome E: knowable novel
consequence without novel-instance action influence.

The 4.37 action path and its C18 NULL are unchanged.
